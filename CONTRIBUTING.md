# Contributing to NOX Pocket AI

This is an early, reproducible Windows USB LLM learning project. Issues, tested compatibility fixes and clear documentation are welcome.

1. Open an issue with Windows version, CPU, RAM, USB filesystem, exact error text and reproduction steps.
2. Never post passwords, personal chat history, private system details or credentials.
3. Preserve the local-only default network binding (127.0.0.1). Do not silently enable LAN or internet exposure.
4. Don't commit .gguf, .zip, .exe or downloaded .dll files. The setup script fetches third-party components from publishers instead.
5. For changes to download sources, explain upstream provenance, licences and verification methods.
6. Mark as tested only the platforms/hardware you have actually used.
